# Public Wall

A simple website where anyone can say what they want on the internet anonymously.

## 🚀 Features
* **Post Instantly:** No login or account needed.
* **Live Feed:** Read what others are thinking.
* **Simple Design:** Clean and easy to read.

## 💻 How to Run
1.  Download or clone this repository.
2.  Open `index.html` in your web browser.

## 🛠️ Built With
* HTML
* CSS
* JavaScript
